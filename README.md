# Application Machine Learning for Risk Prediction using Synthetic Lung Cancer Paitent Data
The primary aim of this research is to evaluate 3 machine learning models, **Extreme Gradient Boost (XGBoost)**, **Support Vector machine (SVM)**, and **Logistic regression (LogReg)** to yield the best results in predicting whether a patient having lung cancer based on their symptoms and medical records. MITRE's open-source Synthea platform was used to train these machine learning models on the **Jupyter Notebook** using Python 3 (ipykernal); with its given dataset that has thousands of synthetic patients and 791 features that contribute to identifying lung cancer. 
## 📊 Dataset:
- [Synthetic Lung Cancer Paitent Data(Havard Dataverse)](https://dataverse.harvard.edu/dataset.xhtml?persistentId=doi:10.7910/DVN/Q5LK5A)
## 📄 File Description:
1. `LUNGPATH DISCOVERY GROUP IEEE PAPER.pdf` - The research paper written after conducting the study, the format is based on the [IEEE conference paper template](https://view.officeapps.live.com/op/view.aspx?src=https%3A%2F%2Fwww.ieee.org%2Fcontent%2Fdam%2Fieee-org%2Fieee%2Fweb%2Forg%2Fconferences%2Fconference-template-letter.docx&wdOrigin=BROWSELINK)
2. `MACHINE PROJECT - LungPath Discovery Group.ipynb` - The methodology how the study is done. Google Colab and Jupyter Notebook was used for this, thus this file can run either of them.
3. `synthea-lc-dataset-codes.csv` - Provided by the Dataverse Havard, this is a dataset code that is used for descriptive reference to the dataset's number coded features.
4. `synthea-pt60k-lc-data-sel-convert.csv` - Provided by the Dataverse Havard, this the dataset that the study is fully based on.

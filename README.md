# Application Machine Learning for Risk Prediction using Synthetic Lung Cancer Patient Data
This research is to evaluate 3 machine learning models, **Extreme Gradient Boost (XGBoost)**, **Support Vector machine (SVM)**, and **Logistic regression (LogReg)** to yield the best results in predicting whether a patient having lung cancer based on their symptoms and medical records. MITRE's open-source Synthea platform was used to train these machine learning models on the **Jupyter Notebook** using Python 3 (ipykernal); with its given dataset that has thousands of synthetic patients and 791 features that contribute to identifying lung cancer.
